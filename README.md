
Developed an OOP-based Shop Management System in C++ with features like admin authentication, inventory management, product categorization (Electronics, Clothing, Study Material), and persistent data storage using CSV files.

Implemented customer functionalities including product search, add-to-cart, purchase, and automated bill generation, along with admin capabilities to add, update, and delete products.
